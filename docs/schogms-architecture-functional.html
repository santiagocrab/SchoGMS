2. Functional Design

Eight main functions of SchoGMS — what each one does and which files/tables support it.

A. Authentication & Security
  • Staff login (email or username) login.php
  • Email verification — 6-digit code (2FA) verify.php, verify_code.php
  • Account status: pending, active, restricted users table
  • Failed verify logging verification_attempts
  • Dean / program chair separate login tables assigned_dean, assigned_program_chairs
B. User & Campus Administration
  • Create and manage staff accounts admin/user-management.php
  • Assign role and campus users, campuses
  • Admin dashboard statistics admin/dashboard.php
  • Send welcome / verification email on create inc/admin_user_create.php
C. CHED Beneficiary Masterlists
  • Import TDP roster from Excel ched_masterlist
  • Import TES roster from Excel ched_masterlist_tes
  • Campus-scoped lists (chairman: all; coordinator: one campus) sheet_name / campus
  • Upload log and error counts ched_upload_log
D. Registrar Data & Documents
  • Registrar masterlist import/view registrar_master_list
  • Upload COR (Certificate of Registration) document_uploads
  • Upload COG (Certificate of Grades) category COR / COG
  • Preview documents in browser view_document.php
E. Validation & Compliance
  • Compare CHED vs registrar records validate.php
  • Check COR/COG presence by student name document_uploads join
  • Set validation status: Validated / Failed validation_status
  • Export validation remarks (Excel) validated_remarks.php
  • Bulk auto-validate TDP auto_validate_tdp.php
F. Annex 7 — Submit, Review, Approve
  • Coordinator uploads Annex 7 Excel submit_form.php, upload_file.php
  • Status: Pending → Approved / Rejected file_submissions
  • Chairman preview and decision anex-form2.php, update_status.php
  • Email to coordinator on approval SMTP notification
G. Campus Hierarchy (Assignments)
  • Coordinator assigns campus directors coordinator/directors.php
  • Director assigns college deans director → assigned_dean
  • Dean assigns program chairs dean → assigned_program_chairs
  • College/course catalog schogms_colleges, schogms_courses
H. Reporting & Dashboards
  • Role dashboards with counts and charts index.php per role
  • Verified scholars / billing import (optional) verified-scholars.php
  • DataTables lists and filters masterlist pages
  • CSV/Excel exports masterlist_exports, PhpSpreadsheet
Administrator Chairman Coordinator Registrar Director Dean Program Chair
Not in current build: Student or guardian login, online scholarship application form, in-app notification center, or live admin audit log UI (logs page uses sample data).
