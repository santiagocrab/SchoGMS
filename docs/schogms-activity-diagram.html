How SchoGMS Works

Scholarship and Grants Management System — one path from new staff account to approved campus report. Read top to bottom.

Administrator Any staff (first login) Coordinator Registrar Chairman System
Phase 1 — Get access Before anyone can work on scholarships
Admin
Create staff account Adds coordinator, registrar, chairman, or director with email and campus.
Staff
Receive verification code by email 6-digit code confirms the account is real (shown as 2FA on login screen).
Staff
Enter code on Verify page Wrong code → try again. Correct code → account becomes active.
Staff
Log in and open dashboard Each role sees their own menu (coordinator, registrar, chairman, etc.).
Phase 2 — Load scholar names and documents Scholars are added as a list — they do not log in themselves
Chairman / Coord
Upload CHED scholar list (Excel) Official TDP/TES names go into the system for the campus.
Registrar
Upload COR and COG files Certificate of Registration and Certificate of Grades per student.
Phase 3 — Check if everything matches Coordinator compares lists and documents
Coordinator
Run validation Compare CHED list vs registrar records and uploaded COR/COG.
Coordinator
Do name, enrollment, and documents match?
Yes → Mark validated
No → Mark failed
Both paths continue to Phase 4
Phase 4 — Submit and approve campus report Annex 7 workflow
Coordinator
Upload Annex 7 report Campus utilization report sent to chairman — status: Pending.
Chairman
Review Annex 7 file Preview in system, then approve or reject.
Chairman
Approve or reject?
Approve → Email coordinator
Reject → Record decision
System
Save results for reports Dashboards, exports, and records stay in SchoGMS for monitoring.
End — Scholarship cycle recorded
Important for your paper: SchoGMS is built for staff roles (admin, coordinator, registrar, chairman, director, dean, program chair). There is no student or guardian login in the current system — scholar names only appear on uploaded lists.
